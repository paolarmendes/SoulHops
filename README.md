# 🍺 Soul Hops — Restaurant Website

A multi-page restaurant website created as an independent personal project using **HTML5, CSS3, and JavaScript**.

Soul Hops is a craft beer and gourmet burger restaurant concept. The website features a modern, dark-themed design with vibrant lime-green accents, showcasing the restaurant's menu, craft beers, events, and locations.

## 🌐 Live Demo

**[Visit Soul Hops Website](https://paolarmendes.github.io/SoulHops/index.html)**

## ✨ Features

- **Homepage:** Introduces the restaurant with a visual hero section, restaurant information, and weekly events.
- **Food Menu:** Displays burgers, appetizers, and other menu items.
- **Craft Beer Selection:** Showcases different craft beer options, including IPAs, Pilsners, Ales, and Stouts.
- **Restaurant Locations:** Provides information about the restaurant's locations.
- **Delivery Options:** Includes external links to iFood and Keeta.
- **Interactive Navigation:** Includes a dropdown menu for delivery options and navigation between website pages.
- **Responsive Design:** Uses custom CSS to adapt the layout to different screen sizes.
- **Scroll Animations:** Uses JavaScript and the Intersection Observer API to animate elements as they appear on screen.

## 🛠️ Technologies

- **HTML5:** Semantic page structure and content organization.
- **CSS3:** Custom styling, layouts, animations, and responsive design.
- **JavaScript:** Interactive navigation, dropdown functionality, scroll effects, and DOM manipulation.
- **Git & GitHub:** Version control and source code management.
- **GitHub Pages:** Website hosting and deployment.

## 🎨 Design

The website uses a dark visual identity inspired by the restaurant's brand.

**Typography:**

## 🚀 Getting Started

### Prerequisites

- A web browser (Chrome, Firefox, Edge, etc.).
- A code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/paolarmendes/SoulHops.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or use the Live Server extension.

No additional dependencies or frameworks are required.
